AI-Based Autonomous NPC Agent

Training an Intelligent Combat Agent Using PPO Reinforcement Learning

Project Objective

The objective of this project is to develop and train an autonomous non-player character (NPC) agent in a 2D tactical combat environment using Reinforcement Learning. The agent learns to navigate barriers, gather healing targets, and make real-time decisions on when to strike the player and when to raise its defensive shield to block incoming attacks.

Environment & Space Specifications

The custom Gymnasium wrapper maps a continuous 15-dimensional observation space containing relative angles, distance representations, active targets, player health, and attack swing flashes.

The action space is MultiDiscrete([9, 3]), offering the agent 9 movement actions (8 cardinal/diagonal directions + stay still) and 3 combat states: 0 (idle), 1 (attack), and 2 (block/shield).

Key Design Decisions

Combat Range Equalization

The scripted player originally out-ranged the NPC (70px vs 55px). In initial runs, the agent learned that moving close to attack was suicide and never engaged. Increasing the NPC's attack range to 75px allowed the agent to trade hits safely and learn combat utility.

Anti-Turtling Reward Shaping

A high block reward (+2.0) led the PPO agent to stand still and hold the shield indefinitely (reward hacking). Reducing the successful block reward to +0.5 and increasing the idle-defend penalty to -0.04 successfully forced the agent to strike the player to gain higher positive rewards (+6.0).

Facing Logic & Smooth Interpolation

Action sampling in stochastic predictions caused rapid orientation snaps (spinning). This was fixed by locking the NPC's gaze onto the player within close range, and smoothly interpolating its angle rather than snapping instantly.

Conclusion

The project demonstrates that structured reward shaping and space rebalancing are crucial for stable RL training in action-adventure games. With proper range alignment and anti-turtling guards, the PPO policy effectively masters active combat, dynamically positioning itself, landing hits, and successfully timing shield blocks.
